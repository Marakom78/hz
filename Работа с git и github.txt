Локально:
1.	Установить локально Git
2.	Задать имя пользователя глобально:
 В командной строке ввести
	git config --global user.name "<ваше_имя>"
    git config --global user.email "<адрес_почты@email.com>"

3.	В командной строке перейти в папку проекта.
Инициализируем репозиторий:
	git init
Добавляем все файлы проекта:
 	git add .
Делаем первый коммит (комментарий обязательно): 
	git commit -m "first commit"

Удаленно:
4.	Зарегистрироваться на github.com
5.	Создаем на github.com пустой публичный репозиторий с настройками по умолчанию.
6.  В командной строке:
	Подключение удаленного репозитория
		git remote add github https://github.com/myuser/project
	Установка ветки и отправка в удаленный репозиторий
		git push -u github master

7.	Ссылку на свой проект в github даем преподавателю
